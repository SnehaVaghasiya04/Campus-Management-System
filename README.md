#  Campus Management System

##  Overview

Campus Management System is a web-based application developed to manage School, College, and Hostel operations from a single platform. The system provides separate dashboards for administrators, staff members, faculty members, students, parents, and hostel management.

The main objective of this project is to simplify campus administration, improve communication, and provide an efficient management system for educational institutions.

##  Installation

1. Clone the repository

```bash
git clone https://github.com/SnehaVaghasiya04/Campus-Management-System.git
```

2. Import the SQL file into MySQL.

3. Configure database connection settings.

4. Start Apache and MySQL using XAMPP.

5. Open the project in your browser:

```text
http://localhost/campus_management
```
